# QA Notes

Use this folder for temporary but worth-keeping quality, design, and deployment verification notes.

Examples:

- CRM Analytics dashboard design QA
- deployment validation snapshots
- focused review notes tied to screenshots or demo evidence

Do not keep local-only scratch output here when it can be regenerated. Ephemeral screenshots, browser traces, and intermediate files belong in ignored local output paths instead.

If a QA note becomes part of the maintained Salesforce workflow, move it under
`salesforce/docs/` instead of duplicating it here.
